# OpenSkill Academy

**100% Free Learning Platform** – Complete free replacement for Skill Up / Codiea paid short courses.

## Features
- Bilingual: English + Natural Roman Urdu
- Visual-first lessons (diagrams, flowcharts, roadmaps)
- Project-based curriculum (beginner → intermediate → advanced → capstone)
- Free official docs, free YouTube, free tools only
- Progress tracking, quizzes with explanations, skill trees
- Dark/Light mode, fully responsive, accessible
- No paid APIs required

## Courses Covered (Free Alternatives)
1. Web Development (Regular + Full Stack path)
2. UI/UX & Graphics Design
3. Digital Marketing + SEO + ASO
4. Content Writing
5. Video Editing
6. Unity 3D Game Development
7. 3D Modeling (Blender)
8. And more structured paths

## How to Run
Just open `index.html` or serve the folder with any static server.

```bash
npx serve .
```
