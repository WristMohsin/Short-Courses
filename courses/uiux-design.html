UI/UX & Graphics Design

Complete free curriculum covering Graphics Design (Regular) and UI/UX Design Bootcamp from Skill Up. Uses free tools (Figma, Photopea, GIMP, Inkscape) and free official resources only.

Beginner → Advanced 100% Free ~150–250 hours

Module 1: Design Fundamentals

1.1 Principles of Design, Color & Typography

Learn contrast, hierarchy, alignment, proximity, repetition, balance, color theory, and typography basics.

Free Resources

  • • Interaction Design Foundation (free articles)
  • • Design Principles – free YouTube
  • • Figma Resource Library
  • • Google Fonts

Practice

Create a mood board and a simple brand style guide (logo concept + colors + fonts) for a fictional local business.

Module 2: Free Graphics Tools

2.1 Photopea / GIMP + Inkscape

Photopea.com is free and runs in browser (very similar to Photoshop). GIMP is free desktop software. Inkscape replaces Illustrator for vector work.

  • • Photopea (free online Photoshop)
  • • GIMP Official Tutorials
  • • Inkscape Learn
  • • Photopea Full Course (YouTube)

Practice

Design social media posts, a logo, and a simple poster using Photopea + Inkscape.

Module 3–4: UI/UX with Figma

3.1 Design Thinking, Research, Wireframes & Figma

Figma free plan is enough for learning and most portfolio work.

  • • Figma Design Thinking resources
  • • Figma Learn Design
  • • Figma UI/UX Design Course
  • • Nielsen Norman Group free articles

Practice

Wireframe and design a mobile app (e.g. local food delivery or education app) in Figma with 5–8 screens + interactive prototype.

Capstone Project

Complete UI/UX case study: Research → Wireframes → High-fidelity UI in Figma → Prototype → Portfolio presentation.

Also create 3–5 graphics design pieces (social posts, logo, poster) for the same brand.
