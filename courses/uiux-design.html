MODULE 1

Design Principles

1. Contrast

Contrast = elements ke beech clear difference. Dark text on light background = high contrast (easy read). Buttons background se alag dikhne chahiye. Accessibility: text contrast ratio ideally 4.5:1+.

2. Hierarchy

Visual hierarchy batati hai pehle kya dekhna hai. Bada bold heading → subheading → body. Size, weight, color se hierarchy banti hai.

3. Alignment, Proximity, Repetition, Balance

  • Alignment: Elements grid/line pe; random placement avoid.
  • Proximity: Related items paas, unrelated door.
  • Repetition: Same button/heading style dobara — consistency.
  • Balance: Page ek taraf bhari na lage.
Practice: 5 sites/apps pe contrast, hierarchy, alignment note karo.

MODULE 2

Color & Typography

Complementary = color wheel pe opposite (strong contrast). Analogous = side-by-side (soft). Brand: 1 primary + 1–2 secondary + neutrals. Tool: Coolors.co

Sans-serif screens pe clear; max 2 font families. Google Fonts free.

Practice: Fictional business — 3 colors + 2 fonts style guide.

MODULE 4

UI/UX Process

  1. Empathize — users ki problem
  2. Define — clear problem statement
  3. Ideate — solutions brainstorm
  4. Prototype — wireframe → clickable
  5. Test — feedback → improve

Wireframe = rough layout pehle. User flow = screen-to-screen path.

Practice: Persona + 5–8 wireframes
