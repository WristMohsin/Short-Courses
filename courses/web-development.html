Module 1: Front-End Fundamentals

Duration: 3–4 weeks • Difficulty: Beginner

1.1 HTML – Structure of the Web

Estimated time: 6–8 hours

Learning Objectives

  • Understand what HTML is and why it exists
  • Write semantic HTML5 documents
  • Use headings, paragraphs, lists, links, images, forms
  • Structure a simple multi-page website

Concept Explanation (English)

HTML (HyperText Markup Language) is the skeleton of every webpage. Browsers read HTML tags and display content. Tags like <h1>, <p>, <a>, <img> tell the browser what each piece of content means.

Roman Urdu Explanation

HTML ko aap webpage ki haddiyon (skeleton) samajh sakte ho. Browser HTML tags padhta hai aur content dikhata hai. Har tag ka apna matlab hota hai – heading, paragraph, link, image wagaira.

Free Resources (Verified Free)

  • • MDN Web Docs – Learn HTML (Official, free, best)
  • • freeCodeCamp Responsive Web Design (Free interactive)
  • • freeCodeCamp HTML Full Course (YouTube)
  • • web.dev Learn HTML (Google, free)

Practice Exercise

Build a personal profile page with:

  • Your name as <h1>
  • A short bio paragraph
  • A list of 5 skills
  • A photo (or placeholder image)
  • A link to your future GitHub

Roman Urdu: Apna personal profile page banao – naam, bio, skills list, photo, aur GitHub link ke sath.

1.2 CSS – Styling the Web

Estimated time: 10–12 hours

Learning Objectives

  • Understand the CSS box model
  • Use selectors, properties, and values
  • Apply Flexbox and basic Grid
  • Make simple responsive layouts

Concept (English)

CSS (Cascading Style Sheets) controls how HTML looks – colors, spacing, fonts, layout. The cascade means more specific rules override general ones.

Roman Urdu

CSS webpage ka look control karta hai – colors, spacing, fonts, layout. Cascade ka matlab hai ke specific rules general rules ko override kar deti hain.

Free Resources

  • • MDN Learn CSS
  • • web.dev Learn CSS
  • • Flexbox Froggy (Free game)
  • • Grid Garden (Free game)
  • • freeCodeCamp CSS Full Course

Practice

Style your HTML profile page. Add a nice color scheme, center the content with Flexbox, and make it look clean on mobile.
