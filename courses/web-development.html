MODULE 2 · CSS

CSS — look aur curly braces { }

CSS rule anatomy

CSS HTML ka color, size, spacing, layout control karti hai. Rule pattern (MDN style rule):

selector {
  property: value;
}

Curly braces { } kyun?

Selector batata hai kis element pe style. { se } tak declarations group hoti hain. Bina braces browser nahi samajhta kaunsi properties is selector ki hain. Same “block” idea JS functions mein bhi.

h1 {
  color: orange;
  font-size: 2rem;
}

Selectors

Type p { } · Class .btn { } · ID #hero { } (unique).

Box model

content + padding + border + margin. box-sizing: border-box se width mein padding+border include — modern layout standard.

MODULE 3 · JS

JavaScript — variables, functions, { }

JS page interactive banata hai: clicks, forms, fetch, DOM updates.

const = no reassign · let = reassign OK · prefer over var (MDN).

const siteName = "OpenSkill";
let score = 0;
score = score + 1;

Functions aur braces

Function body block statement hai jo { } se delimit hoti hai (MDN). Multiple statements group. Control flow (if/for) mein bhi braces recommend — baad mein lines add karte waqt bugs kam.

function greet(name) {
  return "Hello, " + name;
}
const double = (n) => {
  return n * 2;
};
Object { name: "Ali" } = data. function(){ } = code block. Same symbol, different meaning by context.
