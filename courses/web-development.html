MODULE 1 · 3–4 WEEKS

HTML, CSS & Responsive Design

1.1 HTML — Structure of the Web

6–8 hours

HTML is the skeleton of every webpage. Learn semantic HTML5: headings, paragraphs, lists, links, images, forms, and page structure.

MDN — Learn HTML web.dev Learn HTML freeCodeCamp Responsive Web Design freeCodeCamp HTML Full Course
Practice: Build a personal profile page (name, bio, skills list, image, GitHub link).

Quiz: Main heading tag?

<h1>
<head>
<title>

1.2 CSS — Styling

10–14 hours

Box model, selectors, Flexbox, Grid, responsive design.

MDN Learn CSS web.dev Learn CSS Flexbox Froggy Grid Garden freeCodeCamp CSS Course
Practice: Style your profile page with Flexbox. Make it mobile-friendly.

1.3 Bootstrap

6–8 hours

Official Bootstrap 5 Docs Bootstrap 5 Crash Course
Mini project: Rebuild profile with Bootstrap navbar + cards.
MODULE 2 · 4–5 WEEKS

JavaScript

2.1 Core JavaScript

Variables, functions, loops, arrays, objects. Master fundamentals before frameworks.

javascript.info MDN Learn JavaScript freeCodeCamp JS freeCodeCamp JS Full Course
Projects: Calculator + To-do list (pure JS).

2.2 DOM, Fetch & JSON

javascript.info DOM MDN Fetch API
Project: Weather or Quote app using a free API.
MODULE 3 · 1 WEEK

Git & GitHub

Official Git Docs GitHub Skills Git Crash Course
Practice: Push every project to GitHub with clean commits.
MODULE 4 · 4–6 WEEKS

Frontend Framework

Choose one: Vue (easier) or React (more jobs). Learn components, state, routing.

Vue.js
Official Vue Tutorial Vue Guide
React
Official React Learn freeCodeCamp Frontend

MODULE 5 · 5–7 WEEKS

Backend — PHP & Laravel

Laravel is the modern PHP framework (MVC, Auth, Eloquent, APIs).

PHP Manual Laravel Docs Laracasts Laravel From Scratch
Project: CRUD blog/inventory with authentication.
FINAL PROJECT

Capstone — Full Stack App

Build and deploy a complete app (task manager, job board, or mini e-commerce) with:

  • Authentication (register / login)
  • Database + CRUD
  • Responsive frontend
  • Live deployment (Railway / Render free tier)
  • Public GitHub repo + README

This becomes the main piece of your developer portfolio.

Completion checklist

  • ☐ All module exercises finished
  • ☐ At least 4 projects on GitHub
  • ☐ Capstone deployed with live link
  • ☐ README for every major project
