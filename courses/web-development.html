MODULE 1

HTML — Structure of the Web

What is HTML?

HTML (HyperText Markup Language) webpage ka skeleton hai. Browser HTML tags padhta hai aur content dikhata hai. Har tag ka matlab hota hai — heading, paragraph, link, image, form, etc.

Example: <h1> main heading, <p> paragraph, <a> link.

Basic HTML Document

<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Hello World</h1>
  <p>This is my first webpage.</p>
  <a href="https://google.com">Go to Google</a>
</body>
</html>
